# JLox

A Lox programming language interpreter in java from the book 
*Crafting Interpreters*.

## Try it out

I tested this on openjdk-27 but it should work with java > 11.
If you have [just](https://github.com/casey/just) installed, run  
`just run` otherwise run `./gradlew run --console=plain`
from the projects root.
